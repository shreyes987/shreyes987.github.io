# Shreyas Basutkar — Senior .NET Developer Portfolio

A responsive React portfolio grounded in Shreyas Basutkar's professional resume and current engineering work. It highlights enterprise .NET experience, technical leadership, selected projects, and the active Spice ERP build.

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
pnpm preview
```

The site uses a relative Vite base path, so it works both on a GitHub user page and inside a project repository path. The included GitHub Actions workflow builds and publishes the `dist` directory through GitHub Pages.
